# User Profile Card Generator

## Description
A web application that allows users to create profile cards by entering their name, bio, and image URL.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Features
- User details input form
- Backend processing using Flask
- POST request handling
- Automatic unique Profile ID generation
- Profile card display on the next page

## How to Run

1. Install Flask:
   pip install flask

2. Run the application:
   python3 app.py

3. Open in browser:
   http://127.0.0.1:5000
